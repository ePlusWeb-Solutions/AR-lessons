# مشغل الدروس التفاعلي — نموذج GLB المحسن (`lessons-3d`)
> **موقع مصغر مستقل بالكامل (Standalone 3D Micro-website)**  
> **تطوير وتصميم**: الوكالة للأبحاث الرقمية والتطوير ([alwkala.com](https://alwkala.com))

---

## عن النسخة المحسنة
نسخة مستقلة بالكامل تدمج نموذج **`low_poly_tree.glb`** ثلاثي الأبعاد داخل بيئة **Qahera UI Light Mode** النهارية لتدريس **مثل كلمة طيبة كشجرة طيبة** (سورة إبراهيم: الآيات 24–26، مقرر التفسير ١ — الصف الأول الثانوي).

## التحسينات الهندسية والرسومية
1. **مسار تحميل مزدوج (Dual Loading Pipeline)**:
   - تحميل `assets/models/low_poly_tree.glb` عند التشغيل عبر `HTTP/HTTPS`.
   - التحويل التلقائي إلى `assets/models/low_poly_tree-inline.js` عند التشغيل المباشر عبر `file://` أو عند انقطاع الاتصال.
2. **معالجة الألوان والبيئة (PBR & Tone Mapping)**:
   - تفعيل `THREE.ACESFilmicToneMapping` وترميز `THREE.sRGBEncoding` لتألق الألوان الطبيعية في ضوء النهار.
   - بيئة انعكاس محيطية خفيفة، وظلال ناعمة (`ShadowMaterial`)، وجزيئات ضوئية نهارية عائمة.
3. **التكامل التربوي الدقيق**:
   - دمج قرص العشب الأصلي للنموذج (`Base_Material.873_0`) فوق **مقطع التربة الشفاف والجذور العميقة** (﴿أَصْلُهَا ثَابِتٌ﴾).
   - عزل وإخفاء العناصر الدخيلة (`Axe`, `Stump`, `Mushroom`, `Fungus`, `Plane.336`).
   - توليد عناقيد ثمار ثلاثية الأبعاد متنامية داخل التاج، وحركة تمايل لطبقات الأوراق (`Plane.1065` و `Plane.547`) أثناء الرياح.
4. **واجهة Qahera UI Light Mode كاملة**:
   - خلو تام من الإيموجي (`QAHERA-VISUAL-001`) مع أيقونات SVG 24×24 نقية.
   - حالات `:focus-visible` كاملة لإمكانية الوصول، وشاشة استهلال، وشاشة تهنئة، ونافذة «عن الدرس والمطور».
